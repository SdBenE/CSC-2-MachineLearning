#### About
CSC-2-MachineLearning is a repository that creates and trains a machine learning model to determine an individual's survivability during the Titanic disaster of 1912. This was created as a part of *EGR101 - Introduction to engineering* at California Baptist University and was based on Kaggle's data science challenge [*Titanic - Machine Learning from Disaster*](https://www.kaggle.com/competitions/titanic). The submission of the predictions, labeled under [*predictions.csv*](https://github.com/SdBenE/CSC-2-MachineLearning/blob/main/predictions.csv) received a 75.12% accuracy rating from Kaggle.
